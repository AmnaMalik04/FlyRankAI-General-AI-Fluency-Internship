## Capstone Project

### AI Tutoring Session & Parent Communication Assistant

My final capstone is an n8n-based agent designed to assist a tutor with parent scheduling requests and student attendance monitoring.

The agent consists of two workflows:

- **AI Tutoring Parent Scheduler Assistant** — handles parent requests to reschedule tutoring sessions.
- **Tutoring Session Monitoring Agent** — monitors student attendance and handles absence communication.

The capstone folder contains the workflow files, documentation, evaluation results, limitations and demo.
